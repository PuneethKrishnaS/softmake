# Student Portal Specifications

## Scope
The Student Portal (`student.softmake.in`) coordinates team project lifecycles.

## Features
- **Project Board**: View team members, assigned developers, milestones, and status stage.
- **GitHub Integration**: Direct client-side fetching of repository README guides, release assets, and workspace directories.
- **Support Tickets**: Create bug and support tickets with attachments uploaded to GitHub.
- **Live Ticket Chat**: Realtime WebSocket chat channel with developers working on the tickets.
- **Milestone Payouts**: View advance collections and invoice release dates.
